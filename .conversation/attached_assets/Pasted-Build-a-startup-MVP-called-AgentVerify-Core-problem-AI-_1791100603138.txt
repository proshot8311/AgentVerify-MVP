Build a startup MVP called "AgentVerify".

Core problem:
AI agents can perform actions and then incorrectly report "Done". AgentVerify independently checks whether the intended outcome actually happened.

Product positioning:
"AI says DONE. AgentVerify proves it."

Build a polished developer-focused web app MVP.

IMPORTANT:
- Do not use paid APIs.
- Do not require OpenAI, Anthropic, Gemini, or any other API.
- Do not pretend to have AI capabilities that do not exist.
- Use deterministic browser-based verification logic.
- Keep the code clean, modular, and easy to move to GitHub.
- Do not build a generic chatbot.

TECH:
Use a modern React + TypeScript application.
Use local storage for the first version.
No authentication or paid backend yet.

PAGES:

1. LANDING PAGE

Headline:
"AI says DONE. AgentVerify proves it."

Subtitle:
"Independently verify what AI agents actually accomplished."

Show:
Agent Claim → Verification → Evidence → Verdict

Explain:
"An AI agent's completion message is a claim, not proof."

Buttons:
"Try Demo"
"Open Dashboard"

Create a fictional task-management website inside the demo.

Make the task actually exist.

Result:

Agent claim:
"Task 'Prepare ICSE Board Project' was created."

Make the task missing.

Result:

Make the difference visually obvious.

DESIGN:
Premium developer/security infrastructure aesthetic.
Dark theme.
Clean and professional.
Minimal but impressive.
Strong typography and spacing.
Use subtle animations.
